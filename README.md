# 字幕点検室

SRT字幕をローカルで点検し、公開前に確認したい箇所を日本語のHTMLレポートにまとめる小さなツールです。

Pythonの標準ライブラリだけで動きます。GPU、APIキー、ネット接続、追加パッケージは不要です。元の字幕ファイルは変更しません。

**Project ¥10,000の運営AIが制作した試験版です。** 文字起こし、音声との照合、誤認識の修正は行いません。

## 入手とサンプル

このリポジトリの **Code → Download ZIP**、または **Releases** から取得し、解凍してください。

`examples/demo_review/report.html` をブラウザーで開くと、架空の5字幕を点検したレポートを見られます。実在の利用者による成果ではありません。

## 使い方

Python 3.10以降が必要です。解凍したフォルダーでターミナルを開きます。

Windows（Python Launcherがある場合）：

```console
py -3 shimaku.py "自分の字幕.srt"
```

macOS / Linux（python3がある場合）：

```console
python3 shimaku.py "自分の字幕.srt"
```

入力名に `_review` を付けたフォルダーが生成されます。その中の `report.html` を開いてください。機械処理用の `report.json` もあります。

同じファイルを再点検するときは、新しい出力先を指定します。既存の出力先は上書きしません。

```console
python3 shimaku.py "自分の字幕.srt" --out "再点検1"
```

付属サンプルを自分で点検する例：

```console
python3 shimaku.py examples/demo.srt --out demo_check
```

## 点検するもの

- 終了時刻の逆転・同時刻、字幕の開始時刻の順序
- 入れ子を含む表示時間の重なり
- 短い・長い表示時間、文字数に対する表示速度
- 行の長さ、行数、番号の連番、行前後の空白
- 装飾タグの存在（見た目の数値は参考扱い）

重複は、各字幕に代表となる1件を示します。すべての重複ペア一覧ではありません。
指摘は確認候補です。意図的な重複や改行もあります。指摘ゼロでも内容や音声との一致は保証しません。

## 任意の書式整形候補

```console
python3 shimaku.py "自分の字幕.srt" --out "整形確認1" --normalize
```

`format_candidate.srt` と差分の `changes.diff` が追加されます。番号の連番、行前後の空白、時刻表記、改行コードだけを整えます。
時刻の値、文言、字幕の順番、改行位置は変更しません。意図的な字下げがある字幕では、このオプションを使わないでください。

点検に指摘が残っていても候補は生成されます。修正完了を意味しません。候補を確認してから編集ソフトへ読み込んでください。

## 調整可能な仮設定

既定値は幅40（全角を2、半角を1と数える概算）、12文字/秒、表示0.7〜7秒、最大2行です。
初版の仮設定であり、公式規格や万人の読みやすさ基準ではありません。

```console
python3 shimaku.py "自分の字幕.srt" --width 48 --cps 15 --min-seconds 0.5 --max-seconds 8 --max-lines 3
```

フォント、画面幅、音声、意味、改行の自然さは実際の動画で確認してください。複合絵文字などの幅は概算です。

## 入力形式と制限

番号、`HH:MM:SS,mmm --> HH:MM:SS,mmm`、本文を空行で区切るSRTに対応します。

- 既定の文字コードはUTF-8（BOM対応）。必要なら `--encoding cp932` または `--encoding utf-16` を明示します。
- 不正な形式はブロック位置を報告して中止します。文字コードの勝手な推測や文字の置換は行いません。
- 入力上限は5 MiB / 20,000字幕。ASS / VTT、時刻行への追加指定は未対応です。
- 終了コード0はレポート生成成功、2は失敗です。0は字幕に指摘がないという意味ではありません。

## プライバシー

コードに外部通信・追跡機能はありません。入力の全文とファイル名は生成レポートに含まれるため、共有前に内容を確認してください。
利用者の字幕を自動収集する仕組みはありません。
