字幕点検室 0.1.0 / Project ¥10,000
制作: Project ¥10,000 運営AI

目的
自動字幕などのSRTから、公開前に確認したい箇所を日本語のHTMLにまとめます。
Pythonの標準ライブラリだけで動きます。GPU、APIキー、ネット接続、pip installは不要です。
文字起こしや音声との照合は行いません。検出内容が必要な修正とは限りません。

必要な環境
Python 3.10以降。実際に検証した環境はLinux/Python 3.12です。
Windows/macOSでの実機確認はまだ行っていません。

サンプルを見る
examples/demo_review/report.html をブラウザーで開いてください。
5件の架空字幕を使った機能デモです。実在する利用者の成果ではありません。

使う
ZIPを解凍し、そのフォルダーでターミナルを開きます。
Windows (Python Launcherがある場合):
  py -3 shimaku.py "自分の字幕.srt"
macOS/Linux (python3がある場合):
  python3 shimaku.py "自分の字幕.srt"
完了後、入力名_reviewフォルダーのreport.htmlを開きます。
同じ入力で再点検するときは別の出力先を指定します:
  python3 shimaku.py "自分の字幕.srt" --out "再点検1"

番号・空白の整形候補を出す
  python3 shimaku.py "自分の字幕.srt" --out "整形確認1" --normalize
format_candidate.srtとchanges.diffが追加されます。
元字幕は変更しません。候補を確認し、必要なら自分で編集ソフトへ読み込んでください。
時刻・文言・順番・改行位置は変えず、連番、行前後の空白、時刻書式、改行コードを整えます。
意図的な字下げがある場合は--normalizeを使わないでください。
点検に指摘が残っていても整形候補は生成されます。修正完了を意味しません。

検出
終了時刻の逆転/同時刻、開始時刻の順序、入れ子を含む時間重複、短い/長い表示、
文字数に対する速度、長い行、行数、連番、行前後空白、装飾タグの存在。
重複は各字幕に代表となる1件を示します。すべての重複ペア一覧ではありません。

仮設定
幅40（全角を2、半角を1と数える概算）、12文字/秒、0.7〜7秒、最大2行。
これは初版の調整可能な仮設定で、公式規格や万人の読みやすさ基準ではありません。
例: --width 48 --cps 15 --min-seconds 0.5 --max-seconds 8 --max-lines 3
速度は空白・結合文字・書式制御文字を除く文字数です。複合絵文字などの幅は概算です。
フォント、画面幅、音声、誤認識、意味、改行の自然さは実際の動画で確認してください。

入力形式
番号 / HH:MM:SS,mmm --> HH:MM:SS,mmm / 本文を空行で区切るSRT。
既定はUTF-8（BOM対応）。Windowsの一部ファイルは --encoding cp932、
UTF-16のファイルは --encoding utf-16 を明示してください。
文字化けを避けるため勝手な文字コード推測・置換は行いません。
不正な形式はブロック位置を報告して中止します。5 MiB / 20,000字幕まで。
時刻行への追加指定、ASS/VTT入力は未対応です。装飾の描画は再現しません。
結果はreport.htmlとreport.json。出力先が既存なら中止し、上書きしません。
失敗は終了コード2、レポート生成成功は0。0は字幕に指摘がない意味ではありません。

プライバシー
コードには外部通信・追跡機能がありません。入力の全文はHTMLレポートにも含まれます。
レポートを共有する際は、字幕の内容とファイル名が相手に見える点を確認してください。
利用者のファイルをこのプロジェクトが自動収集する仕組みはありません。

検証

この配布物には実装、テスト、架空のサンプルとHTMLレポートを含みます。内部活動記録と収支は含めません。
